# LED II

**Source:** `LED-II-thumb.png`
**Mode:** Automated attract-mode

## What it shows

Dot-matrix LED display: rows of red dots, marquee-style.

## Behaviour

Scrolls text across the dot-matrix grid on a loop. Same content rule as LED: a built-in default string, overridable via a command-line argument.

## Interaction

None beyond the shared quit/pause controls.

## Assets

Shares the LED rendering framework with `led.md`, `title.md`, and `dooley.md`.
