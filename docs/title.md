## What it shows

LED bit-pattern demo. Two pattern sets at the bottom, read column by column left to right; each column is a set of bits representing a vertical line with a value 0-255.

## Behaviour

Cycles through bit-pattern columns on a loop, animating the vertical-line values over time. Content here is generated/animated rather than literal text, but follows the same built-in-default framework as `led.md` and `led-ii.md`.

## Interaction

None beyond the shared quit/pause controls.

## Assets
